# HoloHunter 隱私權政策更新與帳號設定頁面文案規劃

本文件為 HoloHunter (hOCG 卡牌查價 App) 針對引進 **Google 及 Apple 登入與共通帳號綁定功能** 所撰寫的隱私權政策修訂草案與前端 UI 設定頁面文案。

---

## 第一部分：隱私權政策修訂段落

以下為新增及修訂之隱私權政策條款，建議更新至官方隱私權政策網頁與 App 內置隱私說明中。

### 1. 帳號註冊與登入方式
HoloHunter 採用第三方身份驗證機制。本服務**僅提供 Google 帳號與 Apple ID 的第三方登入服務，我們不會收集、儲存或處理您的密碼，亦不提供自建帳號密碼登入方式。** 您的帳密安全完全由對應的第三方服務商（Google 或 Apple）依其安全機制保障。

### 2. 收集與處理之第三方登入資料
當您使用第三方登入時，我們將收集、儲存並處理以下有限的帳號關聯資料，用以建立及驗證您的身份：
*   **來源供應商 (Provider)**：例如 `google` 或 `apple`。
*   **第三方唯一識別碼 (Provider User ID)**：第三方服務商提供之去識別化唯一 ID。
*   **電子郵件地址 (Email)**：
    *   **Google 登入**：您的 Google 帳戶電子郵件。
    *   **Apple 登入**：您的 Apple ID 電子郵件；若您選擇「隱藏我的電子郵件」，我們將接收由 Apple 產生的專屬隨機電子郵件地址（格式如 `*@privaterelay.appleid.com`，即 Apple Private Relay Email）。
*   **電子郵件驗證狀態 (Email Verified)**：由第三方服務商提供的信箱驗證布林值。
*   **登入時間戳記 (Login Timestamp)**：您每次登入系統的時間記錄，用以維護您的登入狀態與安全性。

### 3. 內部使用者 ID (Internal User ID) 核心機制
為確保使用者隱私及系統彈性，**HoloHunter 不以您的電子郵件地址 (Email) 作為唯一的身份追蹤或資料索引依據。** 
每位註冊使用者在系統內部均會指派一個獨立且隨機生成的**內部使用者識別碼 (Internal User ID)**。所有收藏、追蹤清單、推播設定等均連結至此 Internal User ID，避免因第三方電子郵件變更而導致資料遺失。

### 4. 多重帳號綁定與資料歸屬 (Common Account Model)
使用者可在帳號設定中綁定多個登入管道（例如同時綁定 Google 帳號與 Apple ID）。
*   **資料歸屬**：當您綁定多個登入管道後，這些管道均會映射至相同的 **Internal User ID**。無論您使用 Google 還是 Apple 登入，皆可讀取與管理同一份使用者資料。
*   **解除綁定限制**：為確保您能正常登入帳號，**帳號必須至少保留一種有效的第三方登入方式**。當您綁定了 Google 與 Apple 帳號後，您可自由解除其中一個綁定，但系統不允許您解除最後一個登入方式。

### 5. 第三方登入衝突與合併 (Provider Collision / Merge)
若您嘗試綁定的 Google 帳號或 Apple ID 已在系統中獨立註冊為另一個 HoloHunter 帳號：
*   為防範帳號竊取與資料覆寫，系統**不支援自動合併**兩個已存在資料的帳號。
*   您可能需要解除其中一個帳號的綁定，或依循系統提示進行重新驗證。若遇特殊情況，請聯繫客服（客服郵箱/人工流程）協助進行人工處理。

### 6. 使用者資料用途與處理
我們收集與使用您的資料僅限於提供、改善與個人化 HoloHunter 的服務。具體用途如下：
*   **收藏與 Watchlist**：將您關注與收藏的 hOCG 卡牌及價格訂閱儲存至您的帳號，以便在多裝置間同步。
*   **應用程式設定**：儲存您的語言偏好（中文/日文）與幣別偏好（日圓/台幣/美元）。
*   **推播通知權限 (Push Notification Token)**：若您同意接收價格變動通知，我們將收集您的裝置推播 Token。此 Token 僅用於發送特定的卡牌價格波動與系統通知，隨時可在系統設定中關閉。

### 7. 帳號刪除與資料銷毀 (Account Deletion & Data Erasure)
您有權隨時申請刪除您的 HoloHunter 帳號。一旦您提交刪除申請並確認：
*   我們將永久刪除您的 **Internal User ID**、關聯的 **Provider Links (Google/Apple 連結)** 及其所對應的所有使用者資料（包含收藏、設定、Watchlist 及推播 Token）。
*   該操作為**不可逆之操作**，一旦刪除，所有歷史資料將無法復原。

### 8. 第三方服務與合規說明
*   **Apple Private Relay Email 合規限制**：我們承諾嚴格遵守 Apple 開發者規範。來自 Apple Private Relay 的隨機信箱僅用於 HoloHunter 帳號身份核對、發送帳號變更通知及系統必要溝通，**絕不**用於未經您授權的行銷宣傳，亦不提供給任何未授權之第三方。
*   **Google OAuth 最小化權限**：本服務對 Google 帳號的權限請求僅限於最小範圍（即 `openid`、`email` 與 `profile` 基礎授權），且該等資料之使用完全符合「Google API 服務使用者資料政策」（包括「限制使用 Limited Use」要求），不作廣告或未授權之用途。
*   **第三方資料處理者 (Data Processors)**：本 App 之後端驗證與資料儲存採用安全合格的雲端技術（如 Supabase / Firebase）。您的驗證資訊與關聯資料將安全地存放於上述平台的雲端資料庫中，以符合 GDPR 及 CCPA 之個人隱私防護標準。

## 第二部分：App / Web 帳號設定頁面與刪除說明文案

本段落為前端開發工程師提供 UI 介面所需的文字說明、警告標語與對話框文案，以確保使用者在操作帳號連結與刪除時，有清晰的 UI 指引。

### 1. 帳號設定頁面 - 帳號連結狀態 (Account Linking UI Copy)

#### 區塊標題
> **帳號與安全性 (Account & Security)**

#### 說明文字
> 「HoloHunter 採用 Google 與 Apple 第三方登入，無需且不儲存任何密碼。您可以綁定多個登入管道，使用任一帳號皆可同步您的收藏與查價設定。」

#### 狀態欄位文案
*   **Google 帳號**
    *   *未綁定狀態*：`未連結` ➔ [按鈕：連結 Google 帳號]
    *   *已綁定狀態*：`已連結 (example@gmail.com)` ➔ [按鈕：解除連結]
*   **Apple ID**
    *   *未綁定狀態*：`未連結` ➔ [按鈕：連結 Apple ID]
    *   *已綁定狀態 (公開信箱)*：`已連結 (user@icloud.com)` ➔ [按鈕：解除連結]
    *   *已綁定狀態 (私密信箱)*：`已連結 (Apple 私密信箱)` ➔ [按鈕：解除連結]

---

### 2. 解除綁定提示與警告 (Unbinding Warnings)

#### 警告一：解除最後一個登入方式（不允許操作）
*   **觸發時機**：使用者點擊唯一一個已連結帳號的「解除連結」時。
*   **對話框標題**：`無法解除連結`
*   **對話框內容**：`為了確保您能正常登入帳號，系統必須保留至少一種第三方登入方式。請先連結其他登入管道（例如 Google 或 Apple），再嘗試解除此連結。`
*   **按鈕選項**：[確定]

#### 警告二：解除非唯一登入方式（確認操作）
*   **觸發時機**：使用者已綁定 Google + Apple，點擊其中一個「解除連結」時。
*   **對話框標題**：`確認解除連結？`
*   **對話框內容**：`解除連結後，您將無法再使用此帳號登入 HoloHunter。但您仍可使用另一個已連結的帳號登入並存取您的原有資料。`
*   **按鈕選項**：[取消] / [確認解除]

#### 警告三：第三方帳號衝突 (Account Collision / Merge Blocked)
*   **觸發時機**：使用者嘗試綁定 Google 帳號，但該 Google 帳號已被另一個 Internal User 註冊。
*   **對話框標題**：`此帳號已被佔用`
*   **對話框內容**：`您嘗試連結的帳號已關聯至另一個 HoloHunter 帳號。為了保障您的資料安全，我們無法自動合併兩個帳號的資料。請先登入該帳號進行清理，或聯繫客服協助人工處理。`
*   **按鈕選項**：[返回] / [聯絡客服]

---

### 3. 帳號刪除頁面與確認流程 (Account Deletion & Confirmation Flow)

#### 入口按鈕（位於設定頁最下方，紅色文字）
> `[ 刪除 HoloHunter 帳號 ]`

#### 第一步：帳號刪除說明頁面 (Deletion Explanation Screen)
*   **標題**：`刪除您的 HoloHunter 帳號`
*   **說明內文**：
    > **在您決定刪除帳號前，請務必了解以下事項：**
    > 
    > 1. **資料永久抹除**：我們將永久刪除您的 HoloHunter 使用者 ID、Google/Apple 登入綁定關係，以及您名下的所有個人資料，包含：
    >    *   卡牌收藏 (Favorites)
    >    *   追蹤清單與價格訂閱 (Watchlists)
    >    *   個人化顯示設定 (語言、幣別)
    >    *   推播通知 Token
    > 2. **操作無法還原**：一旦刪除完成，您將無法復原任何資料，未來使用相同的 Google 帳號或 Apple ID 登入時，系統將視為全新帳號。
    > 3. **第三方資料授權**：刪除本 App 帳號後，您隨時可前往 Google 帳戶安全性設定或 Apple ID 的「使用 Apple 登入」設定中，移除對 HoloHunter 的授權。
*   **操作按鈕**：
    *   [返回設定] (建議為預設醒目按鈕)
    *   [我已了解，繼續刪除] (建議為淡灰色按鈕，防誤觸)

#### 第二步：確認刪除安全彈窗 (Double Confirmation Modal)
*   **觸發時機**：使用者點擊「繼續刪除」後。
*   **標題**：`⚠️ 確定要永久刪除帳號嗎？`
*   **安全提示文案**：`此操作將無法復原。請在下方輸入「DELETE」以確認您的刪除意願：`
*   **輸入框 (Text Input)**：`[請在此輸入 DELETE]` (Placeholder: `DELETE`)
*   **按鈕選項**：
    *   [取消] (綠色/灰色，安全)
    *   [確認永久刪除] (紅色，當輸入框內容精確等於 "DELETE" 時才可啟用)
