# HoloHunter 隱私權政策更新與帳號設定頁面文案規劃

本文件為 HoloHunter (hOCG 卡牌查價 App) 針對規劃中引進 **Google 及 Apple 登入與共通帳號綁定功能** 所撰寫的隱私權政策修訂草案與前端 UI 設定頁面文案。

> **⚠️ 實作狀態聲明（Current vs. Future Behavior）**
>
> 撰寫本文件時，HoloHunter 目前為 **純本地端（local-only）應用程式**：
> - **目前行為（Current behavior）**：App 不提供帳號註冊或登入，不進行第三方身份驗證，亦不將任何個人資料上傳至雲端。收藏、追蹤清單、語言/幣別設定等資料僅儲存於您的裝置本機；解除安裝 App 即會移除本機資料。目前尚未串接任何處理帳號資料的第三方處理者，也沒有伺服器端的帳號刪除流程。
> - **未來/上線前置行為（Future / launch-prerequisite behavior）**：以下多數條款（第三方登入、共通帳號綁定、跨裝置雲端同步、伺服器端帳號刪除與寬限期、推播通知遠端下發等）描述的是 **Google/Apple 登入與雲端帳號功能正式上線後** 才會生效的行為，屬於該功能的上線前置條件。這些條款在對應功能實作並上線前 **不代表現況**，並且必須在功能上線的同時完成揭露與落地。

本文件各段落均以標記區分「目前行為」與「未來/上線後行為」，請勿將未來條款誤植為現行政策。

## 第一部分：隱私權政策修訂段落

以下為新增及修訂之隱私權政策條款，建議於 **Google/Apple 登入與雲端帳號功能上線時** 更新至官方隱私權政策網頁與 App 內置隱私說明中。

### 1. 帳號註冊與登入方式

**目前行為**：HoloHunter 目前不提供帳號註冊或登入功能，使用 App 無需任何帳號。

**未來/上線後行為**：帳號功能上線後，HoloHunter 將採用第三方身份驗證機制。屆時本服務**僅提供 Google 帳號與 Apple ID 的第三方登入服務，我們不會收集、儲存或處理您的密碼，亦不提供自建帳號密碼登入方式。** 您的帳密安全完全由對應的第三方服務商（Google 或 Apple）依其安全機制保障。

### 2. 收集與處理之第三方登入資料（未來/上線後行為）

當帳號功能上線且您使用第三方登入時，我們將收集、儲存並處理以下有限的帳號關聯資料，用以建立及驗證您的身份：
*   **來源供應商 (Provider)**：例如 `google` 或 `apple`。
*   **供應商識別碼 (Provider Subject / `provider_subject`)**：第三方服務商所簽發、對本服務而言**持久且具供應商範圍的化名式識別碼 (persistent, provider-scoped pseudonymous identifier)**。此識別碼在同一供應商內可穩定對應到您，並非去識別化 (de-identified) 資料，我們將其視為個人資料加以保護。
*   **電子郵件地址 (Email)**：
    *   **Google 登入**：您的 Google 帳戶電子郵件。
    *   **Apple 登入**：您的 Apple ID 電子郵件；若您選擇「隱藏我的電子郵件」，我們將接收由 Apple 產生的專屬隨機電子郵件地址（格式如 `*@privaterelay.appleid.com`，即 Apple Private Relay Email）。
*   **電子郵件驗證狀態 (Email Verified)**：由第三方服務商提供的信箱驗證布林值。
*   **登入時間戳記 (Login Timestamp)**：您每次登入系統的時間記錄，用以維護您的登入狀態與安全性。

我們向 Google 請求的授權範圍最小化為 `openid` 與 `email`，**不請求 `profile` 範圍**，因此不會收集您的姓名、頭像或地區設定 (name / picture / locale)。若未來確有需要擴充授權範圍，我們將在收集前於本政策明確揭露所收集的欄位與其用途。

### 3. 內部使用者 ID (Internal User ID) 核心機制（未來/上線後行為）

為確保使用者隱私及系統彈性，帳號功能上線後，**HoloHunter 不以您的電子郵件地址 (Email) 作為唯一的身份追蹤或資料索引依據。**
每位註冊使用者在系統內部均會指派一個獨立且隨機生成的**內部使用者識別碼 (Internal User ID)**。所有收藏、追蹤清單、推播設定等均連結至此 Internal User ID，避免因第三方電子郵件變更而導致資料遺失。

### 4. 多重帳號綁定與資料歸屬 (Common Account Model)（未來/上線後行為）

使用者可在帳號設定中綁定多個登入管道（例如同時綁定 Google 帳號與 Apple ID）。
*   **資料歸屬**：當您綁定多個登入管道後，這些管道均會映射至相同的 **Internal User ID**。無論您使用 Google 還是 Apple 登入，皆可讀取與管理同一份使用者資料。
*   **解除綁定限制**：為確保您能正常登入帳號，**帳號必須至少保留一種有效的第三方登入方式**。當您綁定了 Google 與 Apple 帳號後，您可自由解除其中一個綁定，但系統不允許您解除最後一個登入方式。

### 5. 第三方登入衝突與合併 (Provider Collision / Merge)（未來/上線後行為）

若您嘗試綁定的 Google 帳號或 Apple ID 已在系統中獨立註冊為另一個 HoloHunter 帳號，適用以下規則：
*   **不以 Email 自動連結**：系統**絕不**僅因兩個帳號的電子郵件相同（或相符）而自動將其連結或合併。Email 不作為自動連結的依據。
*   **不自動合併資料**：為防範帳號竊取與資料覆寫，系統**不支援自動合併**兩個已存在資料的帳號，亦不會在帳號間自動搬移或複製資料。
*   **雙向重新驗證 (Bilateral Re-authentication)**：任何合併或改綁作業均需您在**同一操作流程中分別完成兩個帳號的身份驗證**，證明您同時掌控來源與目標帳號後始得進行。
*   **保留者與資料轉移規則 (Survivor / Data-transfer rules)**：合併時您需明確指定保留哪一個 Internal User ID 作為**保留帳號 (survivor)**；未被保留之帳號的資料 **不會** 自動轉移至保留帳號，除非您在流程中明確確認要轉移的資料項目。未確認轉移的資料將依第 7 條的刪除/寬限期規則處理。
*   **客服協助的界線 (Support escalation boundaries)**：若無法自助完成，您可聯繫客服協助。客服**僅能**引導您完成上述需經雙向重新驗證的自助流程；客服**不會、也無權**在未經雙向身份驗證的情況下代為合併帳號、搬移資料或解除他人帳號的綁定。

### 6. 使用者資料用途與處理

**目前行為**：收藏、語言/幣別設定與追蹤清單僅儲存於您的裝置本機，用於在本機提供查價與收藏體驗，不會離開您的裝置。

**未來/上線後行為**：帳號與雲端同步功能上線後，我們收集與使用您的資料僅限於提供、改善與個人化 HoloHunter 的服務。具體用途如下：
*   **收藏與 Watchlist**：將您關注與收藏的 hOCG 卡牌及價格訂閱儲存至您的帳號，以便在多裝置間同步。
*   **應用程式設定**：儲存您的語言偏好（中文/日文）與幣別偏好（日圓/台幣/美元）。
*   **推播通知權限 (Push Notification Token)**：若您同意接收價格變動通知，我們將收集您的裝置推播 Token。此 Token 僅用於發送特定的卡牌價格波動與系統通知，隨時可在系統設定中關閉。（推播的遠端下發亦屬帳號功能上線後才提供。）

### 7. 帳號刪除與資料處理 (Account Deletion & Data Handling)（未來/上線後行為）

帳號功能上線後，您有權隨時申請刪除您的 HoloHunter 帳號。刪除採用**寬限期 (grace period) 機制**，流程如下：

*   **待刪除狀態與寬限期 (Pending Deletion & Grace Period)**：提交刪除申請後，您的帳號會進入**待刪除 (pending_deletion) 狀態**並保留一段**寬限期（預設 30 天）**。寬限期內您仍可登入並隨時**取消刪除**以還原帳號；此期間帳號不對外可用（無法用於一般查價/同步）。
*   **寬限期屆滿後的處理**：寬限期屆滿且您未取消時，我們將刪除或以不可回復的方式**去識別化 (de-identify)** 您的個人資料，包括 Internal User ID、Provider Links（Google/Apple 連結）與其所對應的使用者資料（收藏、設定、Watchlist 及推播 Token）。
*   **保留之資料、目的與期間 (Retention)**：基於安全、防詐與稽核目的，部分**去識別化或最小化**的紀錄可能於寬限期屆滿後仍保留一段有限期間，例如：
    *   **稽核與安全紀錄 (Audit logs)**：用於偵測濫用與資安事件調查，保留期間以達成該目的之最短必要期間為限（一般不超過 90 天）。
    *   **合併/衝突處理快照 (Merge / collision snapshots)**：於帳號合併或衝突處理發生時所產生之最小必要快照，用於爭議釐清與防止資料誤刪，於爭議處理完成或不再需要時刪除。
*   **法定保留例外 (Legal exceptions)**：在法律要求的範圍內（例如任何付費功能所涉之交易、稅務或退款紀錄），相關紀錄將依適用法令規定之期間保留，不受前述刪除/寬限期限制；該等紀錄僅用於履行法定義務。
*   **不可逆性說明**：寬限期屆滿並完成刪除/去識別化後，已刪除之個人資料將無法復原。未來使用相同的 Google 帳號或 Apple ID 登入時，系統將視為全新帳號。

### 8. 第三方服務與合規說明

*   **Apple Private Relay Email 合規限制（未來/上線後行為）**：我們承諾嚴格遵守 Apple 開發者規範。來自 Apple Private Relay 的隨機信箱僅用於 HoloHunter 帳號身份核對、發送帳號變更通知及系統必要溝通，**絕不**用於未經您授權的行銷宣傳，亦不提供給任何未授權之第三方。
*   **Google OAuth 最小化權限（未來/上線後行為）**：本服務對 Google 帳號的權限請求僅限於最小範圍（即 `openid` 與 `email`），且該等資料之使用符合「Google API 服務使用者資料政策」（包括「限制使用 Limited Use」要求），不作廣告或未授權之用途。
*   **第三方資料處理者 (Data Processors)**：
    *   **目前行為**：HoloHunter 目前為本地端 App，**未委託任何第三方處理者**處理帳號或個人資料，帳號資料不存在於任何雲端。
    *   **未來/上線後行為**：帳號與雲端同步功能上線時，我們將在此揭露 **實際採用** 的處理者及其細節。若採用 **Supabase** 作為驗證與資料儲存處理者，我們將揭露：其**角色**（身份驗證與資料庫託管之資料處理者 / processor）、**處理目的**（帳號驗證、共通帳號綁定與跨裝置資料同步）、**資料類別**（provider、`provider_subject`、email/Apple relay email、email_verified、登入時間、以及收藏/Watchlist/設定/推播 Token 等使用者資料）、**儲存與跨境傳輸情境**（所選資料區域，以及是否發生跨境傳輸）、以及其**隱私政策與資料處理協議 (DPA) 連結**。在確定並實際採用單一處理者之前，本文件不會宣稱使用 Firebase 或 Supabase 其中任一者。我們也不對特定法規（如 GDPR / CCPA）作出概括式「完全合規」保證；相關法遵措施將於功能上線、處理者確定並完成評估後具體揭露。

### 2. 解除綁定提示與警告 (Unbinding Warnings)

#### 警告一：解除最後一個登入方式（不允許操作）

*   **按鈕選項**：[確定]

#### 警告二：解除非唯一登入方式（確認操作）
*   **觸發時機**：使用者已綁定 Google + Apple，點擊其中一個「解除連結」時。
*   **對話框標題**：`確認解除連結？`

*   **觸發時機**：使用者嘗試綁定 Google 帳號，但該 Google 帳號已被另一個 Internal User 註冊。
*   **對話框標題**：`此帳號已被佔用`

*   **按鈕選項**：[返回] / [聯絡客服]

### 3. 帳號刪除頁面與確認流程 (Account Deletion & Confirmation Flow)

#### 入口按鈕（位於設定頁最下方，紅色文字）
> `[ 刪除 HoloHunter 帳號 ]`

#### 第一步：帳號刪除說明頁面 (Deletion Explanation Screen)
*   **標題**：`刪除您的 HoloHunter 帳號`
*   **說明內文**：
    > **在您決定刪除帳號前，請務必了解以下事項：**
    >
    > 1. **寬限期與待刪除狀態**：提交刪除後，您的帳號會進入「待刪除」狀態並保留 **30 天寬限期**。寬限期內您可隨時登入取消刪除以還原帳號；此期間帳號將暫停一般使用。
    > 2. **寬限期屆滿後的資料處理**：30 天後若未取消，我們將刪除或不可回復地去識別化您的 HoloHunter 使用者 ID、Google/Apple 登入綁定關係，以及您名下的個人資料，包含：
    >    *   卡牌收藏 (Favorites)
    >    *   追蹤清單與價格訂閱 (Watchlists)
    >    *   個人化顯示設定 (語言、幣別)
    >    *   推播通知 Token
    > 3. **部分紀錄之保留**：基於安全稽核與法定義務，部分去識別化或法律要求保留的紀錄（如安全稽核紀錄、任何付費功能所涉之交易/稅務紀錄）可能於刪除後依必要或法定期間保留，僅用於該等特定目的。
    > 4. **完成後不可還原**：寬限期屆滿並完成刪除後，資料將無法復原；未來使用相同的 Google 帳號或 Apple ID 登入時，系統將視為全新帳號。
    > 5. **第三方資料授權**：刪除本 App 帳號後，您隨時可前往 Google 帳戶安全性設定或 Apple ID 的「使用 Apple 登入」設定中，移除對 HoloHunter 的授權。
*   **操作按鈕**：
    *   [返回設定] (建議為預設醒目按鈕)
    *   [我已了解，繼續刪除] (建議為淡灰色按鈕，防誤觸)

*   **觸發時機**：使用者點擊「繼續刪除」後。
*   **標題**：`⚠️ 確定要進入帳號刪除流程嗎？`
*   **安全提示文案**：`送出後帳號將進入 30 天待刪除寬限期，期間可取消還原；屆滿後將無法復原。請在下方輸入「DELETE」以確認您的刪除意願：`
*   **輸入框 (Text Input)**：`[請在此輸入 DELETE]` (Placeholder: `DELETE`)
*   **按鈕選項**：
    *   [取消] (綠色/灰色，安全)
